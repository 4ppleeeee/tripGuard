一个实体，多目的地挂载

Destination 是旅行知识库的第一层确定边界，但不是单父级目录。Canonical Entity 保持唯一身份，Relation 把它挂到多个国家、城市或区域，Source 和 Fact 分开保存。

故宫：多来源归一到一个地点实体

地图、公众号、旅游局抓到的是不同 source document，但都指向同一个故宫实体；事实按来源和版本挂在实体下。

入库流水线

01 Raw Source 抓取中台写入原始来源，不直接覆盖知识。
02 Extract 抽取 mention、目的地、事实和外部 ID。
03 Resolve 规则、地理、外部 ID、LLM 和人审归一。
04 Attach 一个实体挂载多个 destination relation。
05 Retrieve 从任一目的地入口召回同一个实体。
