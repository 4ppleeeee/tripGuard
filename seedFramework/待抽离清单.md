# qnFramework 待抽离清单

> 目标：记录 qnFramework 中仍偏业务的内容。先只登记，不直接迁移。

| 优先级 | 项目 | 当前所在 | 判断 | 建议去向 |
|---|---|---|---|---|
| P0 | BizShareChannels | `share/api/BizShareChannels.kt` | 业务分享渠道组合，含早晚报、AI 问答、新闻妹、礼品卡等 | 临时 `qnCore`，后续回业务 Core |
| P0 | DtPageId | `dt/constants/DtPageId.kt` | 页面 ID 绑定新闻、游戏、付费、AIGC、音频等业务页面 | 临时 `qnCore`；框架侧改成 `String` 或通用 `PageReportId` |
| P1 | NewsChannel | `channel/constants/NewsChannel.kt` | 强新闻频道常量，包括要闻、724、BonBon、热问、历史、收藏等 | 临时 `qnCore`；框架侧只认通用 `channelId` |
| P1 | pay 目录 | `pay/` | 付费、会员、礼品卡、专栏、钻石充值是业务能力 | 临时 `qnCore` 或独立业务付费模块 |
| P1 | qa 目录 | `qa/` | 热问、AI 问答属于新闻业务形态 | 临时 `qnCore` |
| P1 | event / hot / ip 目录 | `event/`、`hot/`、`ip/` | 事件脉络、热榜/加热、IP 季偏新闻业务 | 临时 `qnCore` |
| P1 | tag 业务模型 | `tag/` | 混有 724、早晚报、音频、专栏等业务字段；当前被 `StructWidget`、`ShareBtnWidget`、`CommonTitleBarWidget`、`qnchannel` 等引用，不适合整体迁移 | 后续按最小 `IFrameworkTagInfo` 协议收窄，完整业务 DTO 进临时 `qnCore` |
| P1 | user 业务模型 | `user/` | 混有企鹅号、AIGC、元宝、专栏、身份信息等业务字段；当前被 `StructWidget`、`ChannelWidget`、`ShareBtnWidget`、`IAppLogin`、`video` 等引用，不适合整体迁移 | 后续按最小 `IFrameworkUserInfo` 协议收窄，完整业务 DTO 进临时 `qnCore` |
| P1 | live 中 NewsLive 模型 | `live/` | `NewsRoom`、新闻直播房间模型偏业务 | 通用 live 抽象可留，News 具体模型进 `qnCore` |
| P2 | ShareBtnWidget 默认渠道 | `page/model/ShareBtnWidget.kt` | 默认依赖 `BizShareChannels.eventPost` | 改成调用方传入，或框架内置中性默认 |
| P2 | HomeStateManager 首页首 tab 判断 | `platform/HomeStateManager.kt` | 依赖 `NewsChannel.NEWS_TOP` | 改成注入首页 tabId |
| P2 | RadioScene 默认频道 | `audio/model/Scene.kt` | 默认依赖新闻音频频道 | 改成调用方显式传入 |
